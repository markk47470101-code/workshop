MCP-серверы

        
      


      
      

        
Серверы хранятся в Mark Desk и подключаются к каждому запуску CLI. Через них Claude получает дополнительные инструменты: файлы, браузер, базы данных, сервисы.

        

        

          
          
          
          
        

        
        Если включить, CLI не будет подключать MCP-серверы из своей конфигурации.

        

          

            
Коннекторы аккаунта Claude

            
          

          
Серверы, подключённые в вашем аккаунте на claude.ai (например, Higgsfield): CLI подхватывает их сам. Чтобы Claude мог вызывать их инструменты без подтверждения, включите «Разрешить».

          

        

      


      
      

        
        

        

          
          
          
        


        

          
          
          
          
        


        

          
          
        

        
Разрешения этого сервера настроены по отдельным инструментам. Изменить их можно кнопкой «Разрешения» в списке серверов.

        Подтверждений в приложении пока нет: если не разрешить, вызовы будут отклонены. Токены сохраняются в файле mcp.json в папке данных приложения.

        

        

          
          
          
        

      


      
      

        
Вставьте конфигурацию из документации сервера, например { "mcpServers": { "name": { "command": "npx", "args": ["-y", "..."] } } }. Серверы с уже существующими именами пропускаются.

        
        

        

          
          
        

      


      
      

        

        
Отмеченные инструменты Claude вызывает без подтверждения. Остальные ему недоступны. Новые инструменты сервера по умолчанию не отмечены.
